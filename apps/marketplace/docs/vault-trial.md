# 架空データでの保管庫試用

対象: PR #9の開発版。マージ・配備・公開・本物の資料の持込みを承認する文書ではありません。コウヤさんが試用先と担当を決め、職員への連絡は本人が行います。

## 準備

- 協力者3〜5人。管理者1人、チーム参加者1〜2人、教材の閲覧者1人を決めます。1台を共用する場合も各自の架空IDを使います。
- 個人プロジェクト用の環境だけで起動します。アソシアの業務アカウント・資料・実利用者情報を使いません。
- 教材は架空の短文・自作TXT等に限定します。本物の支援教材、個人情報、組織ロゴを移して動作確認しません。
- 相手は先に登録し、管理者は本人から聞いたユーザーIDを照合して招待します。IDが似ている別人に送らないよう確認します。
- 管理者は自分の教材を保存する個人保管庫と、共同編集できるチーム保管庫の違いを説明します。

## 20〜30分の操作

| 担当 | 操作 | 観察すること |
| --- | --- | --- |
| 全員 | 登録・ログインし、個人保管庫を開く | 追加説明なしで入口が分かるか |
| 管理者 | チームを作り、相手の登録IDを指定して招待 | 教材1本の閲覧共有より広い権限を渡すと理解できるか |
| 参加者 | 自分のアカウントで招待を受諾 | チームの教材を閲覧・編集・削除・共有できると分かるか |
| 管理者・参加者 | 架空教材を保存し、スマホ幅で検索・編集 | 探し方、保存先、更新版、添付の扱いに迷わないか |
| 管理者 | 注意事項を読んで教材1本の閲覧リンクを発行 | 未検査の範囲と共有される内容が分かるか |
| 閲覧者 | 別ブラウザで教材と添付を開く | アカウントなしで読め、編集操作はないか |
| 管理者 | リンクを取り消し、再読込して確認 | 取消後の表示と取得済みファイルの違いが分かるか |
| 全員 | ログアウトし、共用PCの終了を確認 | 個人教材を残さず終了する手順が分かるか |

チーム招待は指定したアカウントのみが受け取れます。教材の閲覧リンクは、転送先も閲覧可能です。どちらも取得済みの内容を遠隔削除する仕組みではありません。
